Other Functions in Make

Saving typing and avoiding repetition (part II)

Example 1

Example 1

Suppose we have the following project with various scripts; each script produces an output file.

File structure (before running make)

project/
  Makefile
  plot1.R
  plot2.R
  plot3.R

File structure (after running make)

project/
  Makefile
  plot1.R
  plot2.R
  plot3.R
  plot1.png
  plot2.png
  plot3.png

Notice that the script files and the PNG files share the same name.

Example 1: Makefile

Makefile
.PHONY: all

all: plot1.png plot2.png plot3.png

# rule 1
plot1.png: plot1.R
  Rscript $<

# rule 2
plot2.png: plot2.R
  Rscript $<

# rule 3
plot3.png: plot3.R
  Rscript $<
  • All rules have the same pattern
  • A PNG target
  • An R dependency
  • Same command
  • We can use the percent symbol % to define a pattern rule

Example 1: Makefile

Makefile
.PHONY: all

all: plot1.png plot2.png plot3.png

# pattern rule
%.png: %.R
  Rscript $<
  • We only need one pattern rule
  • The common pattern in this case is the name of the file
  • % is a placeholder for plot1, plot2, and plot3

Example 1: Makefile

A more complete Makefile with .PHONY targets all and clean

Makefile
.PHONY: all clean

all: plot1.png plot2.png plot3.png

# pattern rule
%.png: %.R
  Rscript $<

clean: 
  rm -f *.png


  • We still have some repetition in the names of the targets
  • Imagine if you had 10, or 50, or a larger number of targets

Example 2

Example 2

Let’s consider a simple project with a more realistic file structure

File structure (before running make)

project/
  Makefile
  code/
    plot1.R
  images/

File structure (after running make)

project/
  Makefile
  code/
    plot1.R
  images/
    plot1.png

Example 2: Makefile

Rule with no Make variables

Makefile
# rule
images/plot1.png: code/plot1.R
  cd code && Rscript plot1.R

Failed attempt with Make variable 👎

Makefile
# rule
images/plot1.png: code/plot1.R
  cd code && Rscript $<


  • Recall that $< is the first dependency
  • In this case $< has the value of code/plot1.R
  • i.e. Rscript $< corresponds to Rscript code/plot1.R 👎
  • $(<D) and $(<F) to the rescue ✅

Example 2: Make $(<D) and $(<F)

  • $(<D) is the Directory of the first dependency
  • $(<F) is the File name of the first dependency

We can use them to rewrite the rule as follows:

Makefile
# rule
images/plot1.png: code/plot1.R
  cd $(<D) && Rscript $(<F)

Example 4

It would be nice to create a variable PNGS for the targets, something like:

Makefile
PNGS = $(wildcard images/*.png)

.PHONY: all clean

all: $(PNGS)

# pattern rule
images/%.png: code/%.R
  cd $(<D) && Rscript $(<F)

clean:
  cd images && rm -f *.png

⚠️ The above Makefile has an issue ⚠️

Example 4

  • It would be nice to create a variable PNGS for the targets.

  • The issue is that if the directory images/ is empty, then Makefile won’t be able to create the appropriate varibale PNGS

  • The solution involves creating a variable for the dependency files, and then use this variable to create a varible for the targets.

  • The Make tool to accomplish this is a so-called pattern substitution

Pattern substitution

There are two ways to create a variable with pattern substitution

Makefile
# pattern substitution (option 1)
VAR1 = $(patsubst PATTERN,REPLACEMENT,$(VARIABLE))


Makefile
# pattern substitution (option 2)
VAR2 = $(VARIABLE:PATTERN=REPLACEMENT)

Example 4: pattern substitution (opt 1)

Makefile
# dependency files
RS = $(wildcard code/*.R)

# target files (using pattern substitution)
PNGS = $(patsubst code/%.R,images/%.png,$(RS))

.PHONY: all clean

all: $(PNGS)

# pattern rule
images/%.png: code/%.R
  cd $(<D) && Rscript $(<F)

clean:
  rm -f $(PNGS)

Example 4: pattern substitution (opt 2)

Makefile
# dependency files
RS = $(wildcard code/*.R)

# target files (using pattern substitution)
PNGS = $(RS:code/%.R=images/%.png)

.PHONY: all clean

all: $(PNGS)

# pattern rule
images/%.png: code/%.R
  cd $(<D) && Rscript $(<F)

clean:
  rm -f $(PNGS)
